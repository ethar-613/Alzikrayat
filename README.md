# Alzikrayat Project

~ web advanced project 1
~ ايثار عماد الدين احمد - تقانة معلومات

## Description:
   - Alzikrayat is a photo sharing web application project built for advanced web technologies course.
   - for guests the website let them see the home page that have statistics about the users registered,photos   uploaded, and  comment count. let themsee about us page, gallery, users profile,  and photo details show
   - asking him to login if he want to upload photo , make profile , comment in photos , to let other users to tag him.
   - the whole application is built from scratch using a hand-written MVC structure and physical 3-Tier architecture 
   - did not use and external framework, CMS, or ORM anywhere.



## Technologies:
   - PHP 8
   - MYSQL
   - JavaScript
   - HTML5
   - Bootstrap css 5
   - CSS 3
   - RegEx 
   


## How to run(on XAMPP):
   1. copy project folder(AlzikrayatAPP) to `C:\xampp\htdocs\`
   2. open XAMPP controller panel and start **Apache** and **MySQL** 
   3. open **phpmyadmin** on browser at `http://localhost/phpmyadmin`
   4. import `databaseSQL/schema.sql` that will create the database with all its tables. find it in project directory
   5. check `config/app.php`. it have the database connection data it is the default XAMPP install setting. you change it if your setup is different. **[host name , user name , password , database name]**.
   6. open the project in the browser with 
   ```
   http://localhost/AlzikrayatAPP/public/
   ```
   7. register a new account and start uploading photos. and enjoy :>
